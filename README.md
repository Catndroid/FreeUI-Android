使用指南：

打开源码（.sb3）请使用turbowarp并开启扩展非沙盒模式

打开网页（.html）请使用edge浏览器

仅有安卓安装包（.apk）供安卓手机使用


注意事项：

性能消耗较大，尤其需要大量运行内存，建议内存规格12GB起步并打开内存扩展

请使用edge浏览器打开网页（.html），如果长时间加载不出可尝试重新打开或切换网络

如果进入后图片不显示或乱码，大概率是因为内存崩溃
